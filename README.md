# Frame Window

A Geode mod for Geometry Dash focused on practice and input-event logging.

## Current features
- Menu button describing the mod.
- Records gameplay button DOWN/UP events to the Geode log.
- Tracks elapsed time and update-frame count for each attempt.
- Does not automate gameplay or modify physics, collision, or hitboxes.

## Build
Pushes and manual runs of GitHub Actions build Android 32-bit and 64-bit packages. Download the `Frame-Window-Android` artifact from the workflow run.

The project is based on the official Geode example-mod structure.
